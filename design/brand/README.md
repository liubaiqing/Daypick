# 拾日 · Daypick 图标设计稿 01

状态：**旧方案未获认可，保留作历史对照**。当前提案为 [拾光弧](picklight/README.md)，仍待确认、尚未接入应用。未生成 ICO，不修改现有 Windows 图标。

圆润 D 对应 Daypick，内部偏上圆日对应“日”；下弧包容日光，表达拾取一天。雾蓝与杏黄形成冷暖对比，透明背景，无日历格、对勾、文字或外框。主体宽792px、高800px，约占1024px画板78%；圆日直径220px，约为主体宽28%。

## 文件

- `daypick-icon.ai`：Illustrator 2026 原生源文件，RGB／1024×1024；D 主体、圆日、高光与暗部、隐藏的预览背景四层。D 是带真实镂空的复合路径，圆日为独立路径，渐变可编辑，不依赖字体或嵌入图片。
- `daypick-icon.svg`：Illustrator 导出的透明矢量图。
- `daypick-icon-1024.png`：透明主图。
- `daypick-icon-preview.png`：1600×1060 对照图，三种背景与实际像素尺寸；查看小尺寸时请使用100%缩放。16／24／32px采用平面填色、去高光，48／256px保留渐变。
- `create-daypick.jsx`：Illustrator“文件→脚本→其他脚本”运行的原生绘制脚本。**会重建并覆盖同目录的上述四项输出；手工修改AI后应先另存副本，再运行脚本。** 不读写日历数据、不联网。

基础雾蓝 `#729ABC`（亮部 `#B9D3E7`、暗部 `#486D91`）；日光 `#F3BE70`（亮部 `#FFE1A2`、暗部 `#E7A756`）。左上光源，高光仅9%不透明度，无独立描边或外发光。

## 核验

在本机 Illustrator 30.6.0 完成原生绘制、导出与关闭后重新打开；图层及D复合路径可见。SVG含两条path、一个circle和两个线性渐变，无image节点。PNG为1024×1024，角落及内部留白alpha为0，主体和圆日alpha为255。对照检查未见裁切、外侧白边；16px下日光较小，采用简化填色，正式ICO接入前仍应在Windows任务栏实测。
